# Abstract

First- and early-generation Linux-based Smart Televisions (`2012–2016`) represent an under-studied class of consumer cyber-physical systems characterized by tight silicon-to-cloud coupling, asymmetric cryptographic boot enforcement, and rapid software obsolescence. Triggered by an empirical consumer firmware modification failure—specifically an **8-second UI stall (`...`) followed by abort dialog `"REINICIAR OU TENTAR NOVAMENTE"`**—we conduct an end-to-end static reverse engineering, cryptographic verification, supply-chain SBOM, and privacy audit of the **AOC `LE32S5760/20`** (`TPV MTK2K14PLF` / **MediaTek `MT5880`** `ARMv7-A` / Linux `3.0.13`) firmware image (`LE32S5760_V2.011_V0.2.zip`, `SHA-256: 014e235c...`).

By resolving a `64`-byte U-Boot `uImage` misalignment offset on decompressed kernel memory (`scratch/vmlinux.bin` at VA `0xc0008000`), disassembling Thumb-2 Preloader OTP eFuse gates (`0xf0008664 & 0x100000 -> 0xfb000520: b #0xfb000520` permanent halt), and auditing `libdtv_common.so`, `libmtkapp.so`, `dtv_svc`, `SystemManager`, and `libnettv.so`, we establish four primary findings:
1. **Verified Cryptographic Chain of Trust:** We confirm textbook RSA-1024 (`e=3`) modulus enforcement inside `nfsb_rsa_check` (`0xc0028df8`) across all **`36,281` `4 KB` SquashFS blocks** (`12,514` in `rfsA`, `23,767` in `3rdA`) via 2-level `dm-bht` MD5 Merkle trees, proving full-width `mpuint_equal` immunity to Bleichenbacher trailing-garbage attacks alongside an explicit `custom_upgrade_loader.pkg` failure counter-proof.
2. **Root Cause of the 8-Second Update Failure:** ARM32 disassembly of `libmtkapp.so` (`sub_404f28 @ 0x404f54`) proves `<METHOD>PART</METHOD>` emits nonexistent device string `"/dev/nand_10"` (`-22 ENOENT` from `c_fm_erase_flash_part`), while `_phm_upg_model_start_upgrade` (`0x40ae80`) skips dual-bank failover on standalone `3rdp` images.
3. **Asymmetric Userspace & PKI Weaknesses:** We document single-user UID `0` execution without `/etc/shadow` or MAC (`SEC-01`), private `.pem` signing keys bundled inside distributable factory `roda` images (`SEC-02`), `10+`-year EOL TLS/C libraries (`OpenSSL 1.0.0d`, `libcurl 7.21.7`, `libxml2 2.7.8`, `glibc 2.12.2`, `BusyBox 1.15.3`) tracked via `SPDX-2.3` and `CycloneDX 1.5` SBOMs, and an Opera CA store where `57/186` anchors expire prior to `2026` (`9` already expired in `2016`).
4. **Non-Destructive Customization & Epistemic Boundaries:** We construct an offline-verified `19,905`-byte `<TAG>smth</TAG><METHOD>FILE</METHOD>` `.upg` mechanism targeting writable UBIFS `mtd12` (`/3rd_rw`) without touching locked boot partitions, while documenting missing physical PCB teardown verification (`715G7904M` unconfirmed), absent hardware NAND programmer recovery, and uncaptured live wire telemetry explicitly as open empirical limitations.
