# Abstract

First- and early-generation Linux-based Smart Televisions (`2012–2016`) represent an under-studied class of consumer cyber-physical systems characterized by tight silicon-to-cloud coupling, asymmetric cryptographic boot enforcement, and rapid software obsolescence. Motivated by an empirical consumer firmware modification failure—specifically an **`~8`-second UI progress stall (`"..."`) followed by abort dialog `"REINICIAR OU TENTAR NOVAMENTE"`**—we conduct a comprehensive static reverse engineering, cryptographic verification, DWARF/ELF compiler-hardening, X.509 trust-store, and SBOM supply-chain audit of the **AOC `LE32S5760/20`** (`TPV MTK2K14PLF` / **MediaTek `MT5880`** `ARM Cortex-A9 SMP + VFPv3` / Linux `3.0.13`) firmware distribution (`LE32S5760_V2.011_V0.2.zip`, `SHA-256: 014e235c...`, `upgrade_loader.pkg`: `323,840,461` B).

Across seven deterministic proof suites (`evidence/01..07`), ELF/DWARF inspection (`readelf`), OpenSSL X.509 parsing, and automated CI validation (`tests/test_research_suite.py`), we establish five core findings:
1. **Silicon-to-Kernel Chain of Trust & Bleichenbacher `e=3` Immunity:** Correcting a `64`-byte (`0x40`) U-Boot `uImage` misalignment on decompressed kernel memory (`scratch/vmlinux.bin` at VA `0xc0008000`) resolves the `1024`-bit `NFSB` modulus (`0xc0429370`), exponent `e = 3` (`0xc04292f0`), `dm_mount_root_nfsb` (`0xc0009594`), `populate_table_nfsb` (`0xc02243c4`), and `nfsb_rsa_check` (`0xc0028df8`). Verifying the `231`-byte (`0xe7`) packed `struct nfsb_header_v2` across all **`36,281` `4 KB` SquashFS blocks** (`12,514` in `rfsA`, `23,767` in `3rdA`), we prove `mpuint_equal` enforces full-width `1024`-bit equality against $0^{96} \parallel \text{SHA-256}(\text{hdr}[0:0\text{x}67])$, blocking low-exponent trailing-garbage forgeries alongside a failing counter-proof on `custom_upgrade_loader.pkg`. Downstream, Thumb-2 Preloader disassembly proves OTP eFuse `0xf0008664 & 0x100000` drives an infinite hardware halt at `0xfb000520: b #0xfb000520` (`"not secure loader\n"`) on signature failure.
2. **Instruction-Level Diagnosis of the `8`-Second Update Failure & `#DH@FiRm` Encryption:** ARM32 disassembly of `libmtkapp.so` (`sub_404f28 @ 0x404f54`) proves `<METHOD>PART</METHOD>` emits nonexistent device string `"/dev/nand_10"` (`-22 ENOENT` in `c_fm_erase_flash_part`), while `_phm_upg_model_start_upgrade` (`0x40ae80`) skips A/B bank swapping on standalone `3rdp` images. Disassembly of `libdtv_common.so` (`0x098b64`) recovers the hardcoded `0x94102909 * 4` AES key, zeroed-slot MD5 semantics, and **`33`-byte (`\n`-terminated)** `AES_Prod.key/.iv` derivation.
3. **`uenv` DWARF DRAM Refutation & Cross-SDK Provenance:** Inspecting unstripped `ET_REL` object `upgrade_loader.pkg#part:uenv` (`2,384` B, `env.c`) recovers `GCC 4.5.1` (`-Os`), `Tag_DIV_use: Not allowed`, `global_magic = 0x53965368`, and **`global_kernel_dram_size = 0x21fb9000` (`570,134,528` B = `543.72 MiB`)**, refuting earlier `~512 MB` physical DRAM approximations and proving installed DDR exceeds `543.7 MiB`. Concurrently, `DT_RPATH` strings pin `SystemManager` and `netflix` (`p4/w/20150420_194932/.../gnuarm-4.5.1_vfp_ca9`) to **Cortex-A9 VFP**, `libcurl.so.4.2.0` to MediaTek Blu-ray SDK `BDP_V301`, and `dtv_driver.ko` to `Philips_2K13_ODM` + `/dev/eeprom_{0,3,4}`.
4. **Severe Userland & PKI Hardening Asymmetries (`SEC-01`–`SEC-10`):** Despite `libc-2.12.2.so` shipping with `PARTIAL RELRO`, Stack Canaries, and `75` `_FORTIFY_SOURCE` `__*_chk` symbols, **`16/16` (`100%`) audited application/OEM ELFs have `RELRO=NONE`, `Stack Canary=False`, `_FORTIFY_SOURCE=0`, and non-PIE fixed `EXEC` base addresses**, running as single-user UID `0` `root` without `/etc/shadow`. Meanwhile, factory `upgrade_loader.pkg#part:roda` leaks `LT0_UPG_PriKey_Prod.pem` (`SEC-02`), and Opera's `opcacrt6.pem` (`186` certs) embeds `17` OpenSSL 3 parse failures, `1` `MD2` (`1000b`) root, `7` `MD5`, `106` `SHA-1` (`62.7%`), `18` RSA `< 2048b`, `9` roots expired in `2016`, and `57` expired before `2026`.
5. **Non-Destructive Customization & Explicit Epistemic Boundaries:** We construct an offline-verified `19,905`-byte `<TAG>smth</TAG><METHOD>FILE</METHOD>` `.upg` update targeting non-verity UBIFS `mtd12` (`/3rd_rw`) without touching locked boot partitions, while documenting missing physical PCB teardown verification (`715G7904M` = `0` firmware hits), empty GPU directory (`/3rd/Img_Sgx`), absent external NAND programmer recovery, and uncaptured live wire telemetry as explicit empirical boundaries.
