# Conclusion

Through multi-stage binary extraction, ARM32 and Thumb-2 disassembly, mathematical verification of kernel `dm-verity` Merkle trees, DLM cryptographic analysis, and standards-based SBOM auditing, this study establishes a complete technical explanation of both the capabilities and immutable boundaries of the **AOC `LE32S5760/20` (`MediaTek MT5880` / `TPV MTK2K14PLF`)** first/early-generation Smart TV firmware:

1. **Full Custom ROM Replacement Is Cryptographically Locked & Hardware-Hazardous:** Unsigned modifications to `load`, `kerA`/`kerB`, `rfsA`/`rfsB`, or `3rdA`/`3rdB` fail deterministically at OTP eFuse boot traps (`0xfb000520` halt), dual RSA-2048 kernel trailers (`0x25152c`/`0x283f2c`), or `nfsb_rsa_check` (`36,281`-block `dm-bht` MD5 tree + exact `1024`-bit `e=3` verification). Without an external NAND programmer to restore corrupted chips out-of-circuit, flashing custom root/kernel partitions is unsafe.
2. **Legacy Runtime Obsolescence Explains Modern App Failure:** Even with locked boot layers intact or `mtd12` (`/3rd_rw`) safe UI overlays configured, obsolete `2010–2012` binaries (`OpenSSL 1.0.0d`, `libcurl 7.21.7`, `glibc 2.12.2`, `GCC 4.5.1`, Opera `Presto 6213`, Adobe AIR Stagecraft `yt_lbl.swf`, `57/186` expired Opera CAs) prevent running modern TLS `1.2`/`1.3` streaming platforms natively on onboard silicon.
3. **Reproducible Forensic & Safe Preservation Artifacts:** All findings are preserved cleanly across open Python verification scripts, Capstone disassembly logs, `SPDX-2.3` / `CycloneDX 1.5` SBOMs, vector architectural diagrams, and automated tests without distributing proprietary vendor images or signing keys — establishing a reproducible reference baseline for embedded consumer electronics security research.
