# Conclusion

Through multi-stage binary extraction, ARM32 and Thumb-2 disassembly, unstripped DWARF `uenv` metadata recovery, ELF compiler-hardening audits (`readelf`), mathematical verification of kernel `dm-bht` Merkle trees, X.509 PKI auditing, and standards-based SBOM telemetry, this monograph establishes a complete technical explanation of both the cryptographic boundaries and architectural debt of the **AOC `LE32S5760/20` (`MediaTek MT5880` `ARM Cortex-A9 SMP + VFPv3` / `TPV MTK2K14PLF`)** Smart TV platform:

1. **Full Custom ROM Replacement Is Cryptographically Enforced & Hardware-Hazardous:** Unsigned modifications to `load`, `kerA`/`kerB`, `rfsA`/`rfsB`, or `3rdA`/`3rdB` fail deterministically at OTP eFuse gates (`0xf0008664 & 0x100000 -> 0xfb000520: b #0xfb000520` halt), dual RSA-2048 kernel trailers (`0x25152c`/`0x283f2c`), or `nfsb_rsa_check` (`36,281`-block `dm-bht` MD5 tree + full-width `1024`-bit `e=3` verification over packed `231`-byte `struct nfsb_header_v2`). Combined with monolithic proprietary kernel drivers (`dtv_driver.ko`: `/dev/eeprom_{0,3,4}`, `pdwnc_hw.c`, `mt53_fb.c`) and no out-of-circuit NAND flash programmer, flashing unverified custom root/kernel partitions poses severe brick risk.
2. **Legacy Runtime & Cryptography Explain Native Application Obsolescence:** Even where safe UBIFS overlay customization (`mtd12` `/3rd_rw` via `<TAG>smth</TAG><METHOD>FILE</METHOD>`) preserves boot integrity, `2010–2015` runtime constraints—`OpenSSL 1.0.0d`, `libcurl 7.21.7`, `glibc 2.12.2`, `GCC 4.5.1`, Opera `Presto 6213`, Adobe AIR `yt_lbl.swf`, and an `opcacrt6.pem` bundle dominated by `SHA-1` (`106/169`), `MD2`/`MD5`, `<2048b` RSA (`18`), and expired anchors (`57/186` pre-`2026`)—prevent modern TLS `1.2`/`1.3` streaming platforms from functioning natively on onboard silicon (`> 543.7 MiB` DDR3 kernel window `0x21fb9000`, `41`-library `dtv_svc`, `36`-library `libnettv.so`).
3. **Asymmetric DRM vs. Userland Security:** The vendor concentrated engineering effort on DRM/root-of-trust protection (`eFuse + BootROM RSA-2048 + NFSB`), while shipping **16/16 (`100%`) unhardened application/OEM ELFs (`RELRO=NONE`, no stack canaries, non-PIE `EXEC`, `_FORTIFY_SOURCE=0`, UID `0` `root`)** alongside private `LT0_UPG_PriKey_Prod.pem` material inside factory `roda` images (`SEC-02`, `SEC-10`).
4. **Reproducible Preservation Artifacts & Epistemic Rigor:** All findings are reproducible via open Python verification scripts, Capstone disassembly logs, `SPDX-2.3` / `CycloneDX 1.5` SBOMs, vector architectural diagrams, and automated unit tests without redistributing vendor binaries or cryptographic keys, maintaining strict separation between statically proven behavior and unverified physical teardown or live packet capture hypotheses.
