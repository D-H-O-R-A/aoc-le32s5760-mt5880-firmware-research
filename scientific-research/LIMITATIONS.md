# Methodological & Empirical Limitations

Scientific honesty requires explicitly enumerating every dimension where offline static analysis stops short of physical or runtime confirmation:

| # | Limitation Domain | Missing Evidence / Constraint | Effect on Conclusions | Resolution Path |
|---|---|---|---|---|
| **1** | **Physical Mainboard Teardown & Silicon Marking Verification** | No enclosure teardown, photographs, or chip silkscreen capture performed; `715G7904M` PCB ID has `0` hits in binaries (`HARDWARE_PHOTOGRAPHIC_DOCUMENTATION/README.md`). | Exact PCB revision, mounted NAND PN (out of 10 supported IDs), DRAM chip density, tuner IC, and panel timing IC remain **UNVERIFIED**. | Photograph disassembled board with EXIF scrubbed and barcode/MAC redacted. |
| **2** | **Absent External Hardware Chip Programmer** | No RT809H/XGecu NAND programmer or BGA rework rig available. | Deliberately blocked intrusive raw NAND flashing (`load`/`ker`/`rfs`/`3rd`) to eliminate risk of an unrecoverable unit brick. | Acquire external TSOP/BGA programmer & full raw backup dump prior to any raw MTD experiment. |
| **3** | **No Live UART (`ttyMT0`) or Hardware Emulation (`qemu-arm`) Run** | `ttyMT0` getty disabled in `/etc/inittab`; `qemu-arm` absent locally and full-system boot blocked by proprietary `dtv_driver.ko` + MMIO `0xf0008664` / `T8032`. | Exact live `/proc/meminfo`, boot timing delays, runtime `netstat` sockets, and `mt53xx_get_ic_version()` return value remain **UNOBSERVED**. | Capture `ttyMT0` UART TX pads (`115200 8N1`) or build `qemu-arm-static` `LD_PRELOAD` harness per `emulation/`. |
| **4** | **No Controlled Wire Packet Capture (`pcap`)** | No isolated VLAN `tcpdump`/proxy capture executed on live TV hardware. | `291` extracted URLs prove static binary reachability only; live PII transmission fields and DNS latency remain **UNCONFIRMED**. | Run isolated VLAN passive tap (`privacy/PRIVACY_ASSESSMENT.md`). |
| **5** | **Single Firmware Snapshot (`V2.011_V0.2`)** | Only one stock OEM package obtained; no historical (`V1.x`) or newer builds present. | Cannot perform longitudinal binary diffing or definitively characterize string-based downgrade rules inside UI logic. | Archive earlier/later AOC `LE32S5760` official updates if ever surfaced. |
| **6** | **Upstream CVE Patch Backport Uncertainty** | Complete OEM GPL/userspace source trees missing (`STATUS: MISSING_UPSTREAM_OSS_TARBALL`). | SBOM CVEs reflect upstream version series matching (`OpenSSL 1.0.0d`, `libxml2 2.7.8`, etc.) without dynamic call-site exploit verification. | Audit backports if OEM GPL tarball obtained or test via static taint analysis. |
