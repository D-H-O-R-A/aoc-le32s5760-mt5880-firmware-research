# Original Contributions of This Monograph

1. **Discovery of the `64`-Byte `uImage` Offset Trap in Decompressed `MT5880` Kernel Images:** Proved that raw `vmlinux.bin` begins with a `64`-byte (`0x40`) U-Boot `uImage` header (`load=0x7fc0`, `ep=0x8000`); stripping `0x40` bytes realigns all `.rodata` string literals, ARM32 `ldr` pools, the `1024`-bit `NFSB` RSA modulus (`0xc0429370`), exponent (`e=3 @ 0xc04292f0`), and `dm_mount_root_nfsb`/`nfsb_rsa_check` instruction semantics (`evidence/01`, `evidence/02`).
2. **Formal Proof of `nfsb_rsa_check` Immunity to Bleichenbacher `e=3` Padding Forgery + Complete `36,281`-Block Merkle Proof:** Verified offline via raw modular arithmetic (`pow(sig, 3, N)`) and 2-level `dm-bht` MD5 hashing across `12,514` (`rfsA`) + `23,767` (`3rdA`) blocks — paired with a failure counter-proof on `custom_upgrade_loader.pkg` (`evidence/01`, `evidence/07`).
3. **Instruction-Level Diagnosis of the `8`-Second `"REINICIAR OU TENTAR NOVAMENTE"` USB Failure:** Disassembly of `libmtkapp.so` (`sub_404f28 @ 0x404f54`) proved `<METHOD>PART</METHOD>` emits invalid string `"/dev/nand_10"` (`-22 ENOENT` vs `/dev/mtd10`), while `_phm_upg_model_start_upgrade` (`0x40ae80`) disables dual-bank failover on standalone `3rdp` flashes (`evidence/03`).
